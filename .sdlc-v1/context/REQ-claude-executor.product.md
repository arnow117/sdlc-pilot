### 用户场景与测试 *(必填)*

#### 用户故事 1 - 选择所需的委托路径（优先级：P1）

主 Agent 可继续原生工作，也可在当前授权下选择 Claude。此故事单独保护已有用户的可用性；可用能力检测与路由 fixture 独立验证，无需启动模型。

| 场景 | 给定 / 当 / 则 |
|---|---|
| SCN-1 原生无外部依赖 | **给定** 环境缺少 `csd`、Claude、`tmux`，且当前没有选择 Claude；**当** SDLC 路由已有任务；**则** 继续现有原生模型/阶段路径，不要求安装或同意外部执行。（RULE-1） |
| SCN-2 独立普通委托 | **给定** 一项不属于已跟踪 SDLC 的有界普通任务，且其 Claude 执行已获适用授权；**当** 从公共委托入口准备执行；**则** 使用现有会话驱动合同，不因使用 Claude 而新建 Requirement/Feature，也不把普通调用改成 SDLC 编排。（RULE-1、RULE-2） |
| SCN-3 显式选择但条件不足 | **给定** 当前已明确选择 Claude，但缺少相关可执行能力、任务/provider 授权或适用的绕过权限提示授权中的任一项；**当** 准备启动；**则** 报告具体缺口并交还主 Agent，不启动或自动同意，不静默改成其他执行者。仅发现已安装 CLI 或已有 csd 一次性 consent 时也不能补足本次任务授权。（RULE-1） |

#### 用户故事 2 - 验收有界阶段并保持执行控制（优先级：P1）

主 Agent 委托当前阶段后，仍根据实际文件与证据接受结果，并能在纠偏、等待和取消时保持同一任务约束。可通过无 provider 的结果/控制 fixture 与独立场景走查验证；这些是场景输入，不宣称本轮真的启动了 Claude。

| 场景 | 给定 / 当 / 则 |
|---|---|
| SCN-4 有效结果 | **给定** 已授权外部 worker 收到当前完整 brief，其仓库、阶段、Task、写入范围与版本绑定无冲突；**当** 返回现有 canonical result，且声明的 artifact、检查命令/exit、revision 与实际文件一致；**则** 主 Agent 可验收该阶段候选，再按现行协议核对其有序 transition 请求。worker 自身不更新 state；尚需独立 Validate/Review 时继续保留该义务。（RULE-3、RULE-4） |
| SCN-5 缺证据或错版本 | **给定** 输出自报成功，但缺少 canonical 必要内容、实际检查不通过/不可核实，或证据属于其他 revision、worktree、Task 且未核实对当前候选适用；**当** 主 Agent 核对；**则** 候选不能通过，返回具体缺口，不以不适用的旧结果或 worker 文本补成通过，不执行无效或超出 brief 的 transition 请求。仅提交身份变化、相关输入等价且已核实的证据仍可按现行协议复用。（RULE-3、RULE-4） |
| SCN-6 超时仍在运行 | **给定** 等待返回超时，现有会话证据表明原 worker 仍在执行；**当** 主 Agent 继续等待；**则** 保持同一执行者和原工作，不因超时另起 worker、重发同一任务或报告完成。若旧 turn 在间隙已结束，则取得已有结果，避免把它当作未开始的新 turn；无法核实状态时按现行协议报告未知，不能推断已经终止。（RULE-5） |
| SCN-7 同实现者纠偏 | **给定** SCN-5 的问题仍在原合同内且原实现者可用；**当** 下达修正；**则** 同一实现者继续拥有修正与必要检查。若需要合法替换或恢复，原任务授权、失败历史和已用诊断额度继续有效；同一问题已触发现行不收敛停止条件时，换 worker 不能重置它。（RULE-5） |
| SCN-8 取消与恢复 | **给定** 用户明确停止/取消，且同时存在无关会话或共享资源；**当** 收尾或后来恢复该任务；**则** 停止新工作，仅处理已核对属于该任务的执行者/资源并核实结果，保留工作树与必要证据，不停止无关会话或删除共享数据。恢复不能从原授权推断取消已解除，也不能与尚未停止的写者并行编辑。（RULE-5） |
